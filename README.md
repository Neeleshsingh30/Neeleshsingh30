## 🚀 Featured Projects

### 🔍 Production RAG Assistant — Query Routing & Citation Generation
`FastAPI` · `ChromaDB` · `LangChain` · `Streamlit` · `ONNX` · `Render`

An end-to-end **modular RAG system built from scratch** — not a LangChain quickstart clone.

- **Full pipeline ownership:** document ingestion → chunking → vector retrieval → query routing → response generation, with clean separation of concerns across layers.
- **Intelligent query routing** skips retrieval when the query doesn't need it, cutting unnecessary vector lookups and token spend.
- **Pydantic-structured responses** guarantee consistent JSON with **source citations**, directly attacking hallucination at the output-contract level.
- **Decoupled two-service architecture:** FastAPI backend exposing the RAG pipeline over REST + independently deployed Streamlit frontend (Render + Streamlit Cloud).
- **Production debugging, end-to-end:** swapped the PyTorch embedding model for a lightweight **ONNX** alternative, fixed model caching to load embeddings **once at startup**, and resolved dependency, memory, ingestion and retrieval failures via server-log and traceback analysis.
